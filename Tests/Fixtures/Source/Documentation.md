# EasySave v3.0 Documentation

## Overview
EasySave is a comprehensive backup solution for Windows with full and differential backup strategies.

## Features
- Full backup: Complete copy of all files
- Differential backup: Only changed files since last backup
- Centralized logging via Docker
- WPF graphical interface
- Multi-language support (FR, EN)

## Installation
1. Clone the repository
2. Build with dotnet build
3. Run from Visual Studio or dotnet run
